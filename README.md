# 개념의 숲

교과서 개념을 사례와 연결하고, 새로운 상황에 적용해 보는 한국어 학습 웹앱입니다.

## 사용하기

`index.html`을 브라우저에서 열거나 GitHub Pages 배포 링크를 방문하세요. 샘플인 "생태계의 상호작용"으로 바로 시작할 수 있습니다. 다른 단원을 공부할 때는 학습 준비 화면에서 개념 설명, 사례, 비사례, 교과서 메모를 바꿔 주세요.

학습 기록은 사용 중인 브라우저의 로컬 저장소에 저장됩니다. 입력 자료는 서버로 전송되지 않습니다.

## 인트로 영상

시작 화면에서 15초 모션 인트로를 볼 수 있으며, 반복 재생은 음소거 상태로 시작합니다. `assets/concept-grove-intro.mp4`는 1920×1080, 60fps 영상과 자체 제작한 120 BPM 사운드트랙을 포함합니다.

인트로는 `intro.html`에서 시간값으로 렌더링합니다. 다시 만들려면 Node.js, Playwright, Chrome, FFmpeg가 필요합니다.

```sh
npm install
npm run render:intro
```

렌더러는 프레임별 출력을 임시 폴더에 만든 뒤 3개 서브프레임을 블렌딩하고 오디오와 합성합니다. H.264 무손실 인코딩을 사용하며, 반복 재생을 위해 시작과 끝 프레임이 일치합니다.
